# Interface English — учебный корпус

**Назначение:** содержательная база для одного 90-минутного занятия (и для приложения, которое строится вокруг этого материала).
**Ученик:** взрослый, русскоязычный, уровень примерно A2–B1, работает в мебельной фурнитуре.
**Три болевые точки:** (a) кнопки и диалоги на сайтах, (b) меню настроек в играх, (c) профессиональный софт — PTC Creo View Lite.

**Формат таблиц:** `English | Русский | Что реально происходит / простое объяснение | Частая ошибка`.
Вся целевая лексика — по-английски; объяснения — по-русски.

**Легенда достоверности:**
- Без пометки — проверено по документации вендора, стайлгайду или исходникам локализации.
- `UNSURE` — не удалось подтвердить точную формулировку/поведение из первичного источника; объяснение основано на общей практике. Такие места нужно перепроверять перед уроком.

## §0. Одна идея, на которой держится весь урок

Интерфейсный английский — это **не английский язык**, это **закрытый список из ~300 слов**, которые повторяются везде: в браузере, в игре, в CAD-программе, в банковском приложении. Их не надо «учить язык», чтобы понимать, — их надо один раз опознать как список.

Три вещи, которые снимают 90% паники:
1. **На кнопках — глаголы** (что произойдёт). **На вкладках — существительные** (где ты находишься).
2. Почти каждая кнопка — это **одно из четырёх**: согласиться, отказаться, отложить, уйти.
3. Если непонятно ни слова — **Esc / X всегда безопасны**. Они означают «уйти, ничего не поменяв».

### 1.1 Подтверждение, отмена, закрытие

| English | Русский | Что реально происходит | Частая ошибка |
|---|---|---|---|
| **OK** | ОК / Хорошо | Сохранить сделанные изменения **и** закрыть окно. По классическому руководству Microsoft: «OK causes data to be saved and the dialog box to be dismissed». | Думают, что OK = «я прочитал». В окне с настройками OK = «применить». Если не хотел менять — Cancel. |
| **Cancel** | Отмена | Закрыть окно **и отменить** всё, что в нём наменял. Ничего не сохранится. | Путают с «отменить операцию, которая уже идёт». Cancel в диалоге = «не делать», а не «откатить сделанное». |
| **Apply** | Применить | Сохранить изменения, **но окно оставить открытым**. Нужно, чтобы посмотреть результат и продолжить настраивать. | Думают, что после Apply надо ещё раз нажать OK, иначе не сохранится. Не надо — уже сохранено. |
| **Close** | Закрыть | Просто закрыть окно. В окне без настроек (например, «О программе») — то же, что OK. | В окне с настройками Close ≈ Cancel; в окне-отчёте Close ≈ OK. Смотри, есть ли рядом Cancel. |
| **Dismiss** | Скрыть / Убрать (уведомление) | Убрать с экрана сообщение или баннер. Действие **не выполняется и не отменяется** — сообщение просто уходит. | Считают, что Dismiss = «отказаться». Нет: это «не сейчас, убери с глаз». |
| **Confirm** | Подтвердить | Второй, окончательный «да» — обычно для необратимого. | — |
| **Submit** | Отправить (форму) | Отправить заполненную форму на сервер. | Думают «подчиниться» (submit = «покориться» в общем языке). В UI — только «отправить форму». |
| **Send** | Отправить | Отправить сообщение / письмо / файл адресату. | Send — человеку. Submit — системе. |
| **Done** | Готово | «Я закончил здесь» — закрывает экран и сохраняет. Часто на мобильных вместо OK. | — |
| **Got it** | Понятно | Закрыть подсказку. Ничего не меняет. | — |
| **Yes / No** | Да / Нет | Ответ на прямой вопрос в заголовке диалога. | Опасны: надо **прочитать вопрос**, иначе не знаешь, на что отвечаешь. Microsoft советует Yes/No именно тогда, когда хочет заставить прочитать. |
| **Proceed** | Продолжить (несмотря на предупреждение) | «Я понял риск, делай». Обычно после предупреждения. | Не то же, что Next. Proceed = «всё-таки да», Next = «следующий шаг». |
| **Abort** | Прервать | Аварийно прекратить операцию. Старое, редкое слово. | — |
| **Ignore** | Пропустить ошибку | «Знаю про проблему, продолжай без неё». | — |

**Три грамматических вывода, которые даёт один этот экран:**
1. `On / Off` — не всегда «да/нет». В строке `Turn off … effect` значение `On` включает **выключение**. Отрицание внутри метки надо ловить.
2. Метки-существительные с `-ing` (`drawing`, `sheathing`, `centering`, `upscaling`) — это **название процесса**, а не команда.
3. Стек существительных читается **справа налево**: `Autosave Interval` → это `Interval` (промежуток), какой? — `Autosave` (автосохранения).

## §6. Стратегии чтения — переносимый навык

Это главная часть урока: **правила, которые работают на любом незнакомом экране**, даже если половина слов неизвестна.

### 6.1 Где что живёт: глаголы против существительных

- **На кнопках — глаголы.** Save, Delete, Continue, Apply. Кнопка отвечает на вопрос «что произойдёт».
- **На вкладках и в заголовках — существительные.** Home, Markup, Tools, Settings, Structure. Вкладка отвечает на вопрос «где я».
- **В меню — тоже глаголы**, но с многоточием, если будет ещё окно.
- Следствие: если слово на кнопке непонятно — оно **почти наверняка глагол**. Ищите в словаре как глагол, а не как существительное. (`Draw a sword` — вынуть, а не рисовать. `Stamp` — поставить штамп. `Pan` — сдвинуть, а не сковорода.)

### 6.2 Читать глазами до того, как читать словами

| Сигнал | Что означает |
|---|---|
| Кнопка **справа** и **выделена цветом** | Основное действие, которого от вас ждут. Обычно безопасное. |
| Кнопка **красная** | Разрушительное действие: удаление, отключение, отказ. |
| Кнопка **серая (greyed out / dimmed)** | Сейчас недоступна. **Не сломана.** Чаще всего надо сначала что-то выделить. |
| Кнопка **обведена рамкой** | На неё сработает Enter. |
| **Esc** или **X** в углу | Уйти, ничего не изменив. Всегда безопасно. |
| **Многоточие `…`** в конце метки | Действие **не выполнится сразу** — сначала появится ещё одно окно. Проверенное правило Microsoft: `Print` печатает сразу, `Print…` сначала спрашивает. |
| **Двойная стрелка `»`** | Кнопка развернёт окно и покажет больше. |
| **Стрелка вниз `▾`** на кнопке | Есть выпадающий список вариантов. |
| **Замок 🔒** | Нужны права администратора. |

### 6.3 Тип элемента = тип решения

| Элемент | Форма | Правило |
|---|---|---|
| **Checkbox** | Квадрат | Независимая опция вкл/выкл. Можно отметить сколько угодно. |
| **Radio button** | Круг | Из группы работает **только один**. |
| **Toggle / Switch** | Тумблер | Два состояния, применяется сразу. |
| **Slider** | Ползунок | Плавная величина. |
| **Dropdown** | Поле со стрелкой | Один вариант из списка. |

Практическое следствие: **круг — выбери одно; квадрат — выбери сколько хочешь.** Это снимает половину непонимания в cookie-баннерах и меню установки.

### 6.4 Ловить отрицания

Интерфейс любит прятать «не». Опасные конструкции:

| Форма | Пример | Что реально |
|---|---|---|
| `Turn off …` как название настройки | `Turn off Witcher Senses "fish-eye" effect` — On | `On` = эффект **выключен**. Двойное отрицание. |
| `Don't …` | `Don't show this again` | Галочка = «больше не показывать». |
| `Disable …` | `Disable auto-update` — Enabled | «Отключение включено» → обновления выключены. |
| Приставка `un-` | `Unhide All`, `Undo`, `Uncheck`, `Unsubscribe`, `Unmute` | `un-` переворачивает смысл корня. |
| Приставки `in-` / `im-` | `Invalid`, `Insufficient`, `Impossible` | То же. |
| Приставка `de-` | `Deselect`, `Deactivate`, `Delete` | «Обратное действие». |
| `Never` / `No` в опции | `Never allow`, `No thanks` | Отказ. |

**Правило для ученика:** увидел в метке `off`, `don't`, `un-`, `dis-`, `no`, `never` — **остановись и переведи всю строку целиком**, включая значение справа. Одно слово тут ничего не решает.

### 6.5 Стек существительных: читать справа налево

Английский строит длинные цепочки существительных без предлогов. Русский — не строит, поэтому мозг спотыкается.

**Правило: последнее слово — главное. Всё, что слева, — уточнения. Читать справа налево, вставляя «какой?».**

| Стек | Разбор справа налево | Русский |
|---|---|---|
| `Autosave Interval` | Interval → какой? → Autosave | Интервал автосохранения |
| `Frame rate cap` | cap (потолок) → чего? → rate (частота) → какая? → frame (кадров) | Ограничение частоты кадров |
| `Desktop shortcut` | shortcut (ярлык) → где? → desktop | Ярлык на рабочем столе |
| `Key bindings` | bindings (привязки) → чего? → key | Назначение клавиш |
| `Mass Properties` | Properties (свойства) → какие? → Mass | Массовые характеристики |
| `Spin Center` | Center (центр) → чего? → spin (вращения) | Центр вращения |
| `Annotation Sets` | Sets (наборы) → чего? → Annotation | Наборы аннотаций |
| `End User License Agreement` | Agreement → какое? → License → с кем? → End User | Лицензионное соглашение с конечным пользователем |
| `Colour-blind Friendly Witcher Senses` | Senses → чьи? → Witcher → какие? → Colour-blind Friendly | Ведьмачье чутьё, приспособленное для дальтоников |

### 6.6 Суффиксы: три, которые решают почти всё

| Суффикс | Значение | Примеры | Как читать |
|---|---|---|---|
| **-able / -ible** | «можно + сделать» | `Viewable`, `Editable`, `Selectable`, `Available`, `Undoable`, `Clickable` | `View` + `able` = «то, что можно посмотреть». |

| **-er / -or** | тот, кто/что делает | `Finisher`, `Viewer`, `Explorer`, `Slider`, `Installer`, `Cursor` | «Штука, которая…» |
| **-less** | «без» | `Borderless`, `Wireless`, `Endless` | `Border` + `less` = «без рамки». |
| **-friendly** | «приспособленный для» | `Colour-blind friendly`, `User-friendly`, `Beginner-friendly` | Не «дружелюбный», а «удобный для». |

\* `Hidden` — неправильная форма от `hide`, но работает как `-ed`-состояние.

### 6.8 Алгоритм «незнакомый экран за 60 секунд»

Готовая процедура, которую ученик уносит с урока:

1. **Не читай всё.** Найди глазами кнопки: они внизу или справа.
2. **Найди безопасный выход**: `Cancel`, `Close`, `X`, `Esc`. Убедись, что он есть. Дальше можно спокойно исследовать.
3. **Прочитай заголовок окна** — он говорит, о чём вообще речь (существительное).
4. **Прочитай выделенную кнопку** — это то, чего от тебя ждут (глагол).
5. **Проверь на отрицание**: есть ли `off`, `don't`, `un-`, `no`, `never`?
6. **Наведи курсор** на непонятную кнопку и жди 1 секунду — появится `tooltip` с объяснением.
7. **Если слово длинное и составное** — читай справа налево.
8. **Если ничего не помогло** — нажми `Cancel` / `Esc`. Ты ничего не сломал.
